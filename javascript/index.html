Hva med 2 + 3?

Dette er oppgave 2 på arket. Spør hvor mange linjer som kommer ut, og la dem gjette før du går videre. Node regner ut linje 2, men ingen ba den skrive ut svaret.

Gjett rekkefølgen

Node tenker ikke over om det gir mening. Den gjør det som står, i den rekkefølgen det står.

Hvorfor skjer det ingenting?

Den vanligste tidstyven av alle. Node leser fila slik den ligger lagret på disken, ikke slik den ser ut på skjermen. Prikken på fanen betyr «ikke lagret».

Hva mer kan vi skrive i fila?

Variabler, regning, tekst og valg

Del 2. Passer fint som en egen økt. Samme demoer som før, men nå får Node et minne ved siden av editoren.

Hvordan husker Node ting?

Den nye boksen til høyre er minnet til Node. En variabel er en boks med et navn på. Pek på at boksen dukker opp først når linje 1 kjøres.

Linja plukket fra hverandre


let penger = 100;
letlag en ny boks
pengernavnet på boksen, du velger selv
=legg i boksen
100det som skal oppi

= betyr ikke «er lik». Det betyr «legg dette i boksen» 📦

Dette er den viktigste setningen i hele del 2. Resten av regningen gir bare mening når de vet at = betyr «legg i».

Med eller uten hermetegn?

La dem gjette før du kjører.

Kan innholdet byttes ut?

Linje 2 og 4 er helt like, men skriver ulike ting. Koden er den samme, men det er noe annet i boksen. Legg merke til at linje 3 ikke har let: boksen finnes allerede.

Hva med const?

const-boksen er gul og har lås. Å lese fra den går fint. Det er bare å bytte innholdet som ikke går.

Når bruker jeg hva?

let 📦

Innholdet kan byttes ut

penger, poeng, liv, antall

const 🔒

Står fast

prisen på en brus, fødselsåret ditt

Usikker? Bruk const. Krasjer det fordi du vil endre boksen, bytter du til let.

Node er en kalkulator

Spør hvilke tegn som ser rare ut. De fleste har aldri brukt * og / som gange og dele. Siste poeng: punktum, ikke komma.

Hva blir 2 + 3 * 4?

Håndsopprekning: hvem tror 20, hvem tror 14? Det er samme regel som i matten.

Regn med boksene

Pek på at Node slår opp i begge boksene (de lyser grønt) før den regner. Svaret blir en ny boks.

penger = penger - 25?!

I matten er dette en likning uten løsning. Men = betyr «legg i boksen»: først regnes høyre side ut med det gamle innholdet, så legges svaret tilbake i boksen.

Tall eller tekst?

Hermetegn gjør 2 til tekst. Tekst + noe = tekst limt sammen.

Hvor ble mellomrommene av?

Backtick `: Shift + tasten til venstre for Backspace, og så mellomrom

Pluss limer tekst helt tett, så alle mellomrom må man skrive selv inni hermetegnene. Med backticks skriver man setningen som vanlig og putter variablene inn med ${ }.

Er det sant?

true og false er egne verdier, ikke tekst. (Pil ned: alle sammenligningene i én tabell.)

Alle sammenligningene

5 > 3større enntrue
5 < 3mindre ennfalse
5 >= 5større enn eller liktrue
3 <= 5mindre enn eller liktrue
5 === 5er liktrue
5 !== 5er ikke likfalse

Hvis … ellers


if (penger >= pris) {
  console.log("Du har råd! 🎉");
} else {
  console.log("Du har ikke nok penger");
}

if betyr «hvis». I parentesen står det Node skal sjekke.

Er det true, kjøres det som står mellom { }

else betyr «ellers»

Er det false, kjøres dette i stedet

Bare én av dem kjøres, aldri begge

Krøllparenteser: AltGr + 7 og AltGr + 0 (Mac: ⌥ + Shift + 8 og 9)

Har jeg råd?

To kjøringer av nesten samme fil. Pek på at minnet starter tomt igjen ved andre kjøring, og at den gule markøren hopper over linjer. Det er det if gjør: velger hvilke linjer som kjøres.

Husk

  • let lager en boks, const en boks med lås 🔒
  • = betyr «legg i boksen», og høyre side regnes ut først
  • * er gange, / er dele, og gange kommer før pluss
  • "2" er tekst, 2 er et tall
  • Backticks: `En ${vare}`
  • === sammenligner, og svaret er true eller false
  • if velger hvilke linjer som kjøres

Hva om noe skal skje mange ganger?

Løkker og lister

Del 3. Også denne kan tas som en egen økt. Minnet til Node er med hele veien.

Skriv tallene fra 1 til 5


console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

Og fra 1 til 1000? 😩

Vi vil si «gjør dette, igjen og igjen». Det heter en løkke 🔁

while er en if som gjentar seg

if

if (tall <= 3) { console.log(tall); tall = tall + 1; }

Sjekker én gang

while

while (tall <= 3) { console.log(tall); tall = tall + 1; }

Sjekker igjen og igjen, så lenge det stemmer

while betyr «så lenge»

Så lenge det stemmer

Det viktigste steget er når markøren hopper fra } og tilbake opp til while. Stopp der og pek. Boksen tall teller oppover.

Hva om den aldri stopper?

La dem finne det som mangler: linja som endrer tall. Dette skjer med alle før eller siden, og det er ikke farlig. Ctrl + C.

for: det samme, bare kortere

while

let i = 1; while (i <= 3) { console.log(i); i = i + 1; }

for

for (let i = 1; i <= 3; i++) { console.log(i); }

Startlag telleren

Sjekkså lenge dette stemmer

Etter hver rundei++ betyr i = i + 1

De samme tre delene, bare samlet på én linje. i er et vanlig navn på en teller.

Følg for-løkka

Legg merke til rekkefølgen på linje 1: start én gang, så sjekk, og etter hver runde i++ og ny sjekk. (Pil ned: telle nedover.)

Kan vi telle nedover?


for (let i = 3; i >= 1; i--) {
  console.log(i);
}
console.log("🚀");

Gjett først!

2
1
🚀

Start på 3, så lenge i >= 1, og i-- trekker fra 1

Hva om vi har mange ting?

Hakeparenteser: AltGr + 8 og 9 (Mac: ⌥ + 8 og 9)

Det å telle fra 0 er det vanskeligste med lister. Bruk tid på varer[0] og varer[3]. Numrene står over hvert rom i boksen.

Kan lista bli lengre?

Gå gjennom lista

Nå jobber i og lista sammen: i er nummeret, varer[i] er tingen som ligger der. Samme linje skriver ut tre forskjellige ting.

Den enkle måten: for...of

Hver runde får vare en helt ny boks, og det er derfor den kan være const. Når du bare vil ha tingene og ikke numrene, er for...of enklest.

Hva koster handlekurven?

Alt sammen: en liste, en løkke og en boks som samler opp. Pek på at sum lever utenfor løkka og vokser for hver runde.

Hvilken løkke skal jeg velge?

Når du vil …Bruk
gjenta så lenge noe stemmerwhile
telle et bestemt antall gangerfor (let i = 0; …)
gå gjennom alle tingene i en listefor (const vare of varer)

Alle tre kan gjøre det samme. Velg den som er lettest å lese.

Husk

  • while gjentar så lenge sjekken er true
  • Ved } hopper Node tilbake opp og sjekker igjen
  • Noe inni løkka må endre seg, ellers stopper den aldri (Ctrl + C)
  • for har start, sjekk og «etter hver runde» på én linje
  • En liste teller fra 0: varer[0] er den første
  • .length er hvor mange, og .push legger til
  • for...of gir deg én og én ting
